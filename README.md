# Vizuális ETL alkalmazás (2026-LG-02)

Lokális-első vizuális ETL alkalmazás: a felhasználó node-gráfként épít adatfeldolgozási folyamatot (CSV/JSON/XML/API források → transzformációk → export). A forrásadat végig a helyi gépen marad.

- Témavezető: Gergely LABORCI
- Stack: strict TypeScript, Svelte 5 (SvelteKit), Tauri vagy SvelteKit + Bun PoC
- Projektdokumentumok: [`00-project/`](00-project/)
